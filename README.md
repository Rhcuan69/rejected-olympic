One funny single-line sport the Olympics rejected: synchronised screaming, judged on pitch, duration, and how many pigeons flee the stadium.

## Run it

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt` (override with `OUTPUT_DIR`). Pure Python standard library, deterministic — every run writes identical bytes.
